# Canadian Buddhist Places — Research Sources

The first seed dataset was assembled from publicly available directories and official/public organization sources searched on 2026-09-26.

## Source rules

- Seed records are **unverified** until an administrator checks the current source.
- Missing contact details are left blank; the application must never invent them.
- Every imported record keeps a source name, source URL, and source-checked date.
- Before public launch, each record should be checked against the organization's current official website or direct contact information where possible.

## Sources used for the initial research seed

- BuddhaNet World Buddhist Directory — Canada / Alberta listings: https://www.buddhanet.info/wbd/
- Buddhist Churches of Canada directory PDF: https://www.vancouverhistory.ca/wp-content/uploads/2021/02/Buddhist-Churches-of-Canada.pdf
- Royal Thai Embassy Ottawa — Buddhist temples and monasteries: https://ottawa.thaiembassy.org/en/page/buddhist-temples-and-monasteries

## Important

This is a research seed, not a claim that the records are currently accurate. Addresses, phone numbers, email addresses, websites, operating status and affiliations can change. The admin verification workflow must be completed before a record receives a public `verified` status.
